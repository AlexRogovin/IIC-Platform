# Legal Framework: Israel–India Construction Corridor

---

## Israeli Regulatory Layer

### PIBA Procedure 9.4.0001 — Ta'agid (Manpower Corporation) Rules

| Requirement | Detail |
|-------------|--------|
| License type | PIBA (Population and Immigration Authority) |
| Annual license fee | ~₪15,000 |
| Min. equity (351–1,000 workers) | ₪2,000,000 |
| Bank guarantee per worker | ₪9,326 |
| Billing rate to contractors | ₪8,000–11,000/worker/month |
| Worker minimum wage | ₪6,247.67/month (April 2026) |
| Caregiver minimum wage | ₪6,443.85/month (April 2026) |
| Recruitment channel | G2G / bilateral mechanisms ONLY |
| EOR | Ta'agid signs all employment contracts |

### Worker Protections (Israeli Law)
- Workers cannot be charged any fee for employment
- All costs borne by the Israeli Ta'agid
- PIBA monitors compliance; CIMI handles complaints
- 967 complaints filed in 2024 (7.4% of ~13,130 construction workers)

| Requirement | Detail |

## Zero-Fee Principle

> **Absolute rule**: Workers pay nothing for their employment in Israel.

All recruitment costs flow: **Israeli Contractor → Ta'agid → IRA → NSDC**

IIC-Platform enforces this by:
1. Requiring MEA fee receipts from every IRA before worker mobilization
2. Auditing IRA fee claims against the ₪30,000 + GST cap
3. Including zero-fee clause as non-negotiable in all IRA MOUs
4. Flagging any fee-from-worker pattern as immediate contract termination trigger
